# Napojení vlastního GGUF modelu\n\n## Přehled\n\nChatBot-AI můžete provozovat se svým vlastním **GGUF modelem** dvěma způsoby:\n\n### 1. Inference v prohlížeči (WebAssembly + WebGPU)\n\n**Nejjednodušší:** model běží přímo ve vašem prohlížeči, bez backendu.\n\n**Výhody:**\n- Úplné soukromí — data nikdy neopustí váš počítač\n- Žádný server\n- Offline funkčnost\n\n**Nevýhody:**\n- Model se musí vejít do paměti prohlížeče (~3-7 GB v praxi)\n- Pomalejší inference než GPU backend\n\n**Instalace:**\n\n```bash\nnpm install @xenova/transformers\n```\n\nPoužijte knihovnu **Transformers.js** nebo **llama.cpp** přes WebAssembly (emscripten build).\n\n**Příklad s Transformers.js:**\n\n```javascript\nimport { pipeline } from '@xenova/transformers';\n\nconst generator = await pipeline(\n  'text-generation',\n  'Xenova/Llama-2-7b-GGUF',\n  { device: 'webgpu' } // nebo 'wasm'\n);\n\nconst result = await generator(\"Ahoj, jak se máš?\", {\n  max_new_tokens: 100,\n});\n```\n\n---\n\n### 2. Lokální backend (llama.cpp server)\n\n**Doporučeno:** model běží na vašem počítači v standalone serveru.\n\n**Výhody:**\n- Nejrychlejší inference s GPU akcelerací\n- Plná kontrola — můžete vyladit všechny parametry\n- Škálovatelné — podporuje jakýkoli GGUF model\n- Opakovatelné odpovědi — determinismus je v rukou vašeho serveru\n\n**Instalace:**\n\n1. **Stáhněte si llama.cpp:**\n\n```bash\ngit clone https://github.com/ggerganov/llama.cpp\ncd llama.cpp\nmake -j$(nproc)  # nebo: make LLAMA_CUDA=1 (pro NVIDIA)\n```\n\n2. **Stáhněte si GGUF model** (např. z Hugging Face):\n\n```bash\nwget https://huggingface.co/TheBloke/Mistral-7B-GGUF/resolve/main/mistral-7b.Q4_K_M.gguf\n```\n\n3. **Spusťte server:**\n\n```bash\n./server -m mistral-7b.Q4_K_M.gguf \\\n  --host 0.0.0.0 \\\n  --port 8080 \\\n  --gpu-layers 33 \\\n  --n-threads 8\n```\n\n4. **Test:**\n\n```bash\ncurl http://localhost:8080/v1/completions \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"prompt\": \"Ahoj\", \"n_predict\": 50}'\n```\n\n---\n\n### 3. Propojení s ChatBot-AI\n\n#### Varianta A: WebAssembly (prohlížeč)\n\n**Přidejte do `app.js`:**\n\n```javascript\nimport { pipeline } from '@xenova/transformers';\n\nlet textGenerator = null;\n\nasync function initModel() {\n  console.log('Inicializuji model...');\n  textGenerator = await pipeline('text-generation', 'Xenova/Llama-2-7b-GGUF', {\n    device: 'webgpu',\n  });\n  console.log('Model je připraven!');\n  document.body.classList.add('model-ready');\n}\n\nasync function generateReplyLocal(text) {\n  if (!textGenerator) return 'Model se ještě načítá. Prosím počkejte...';\n  \n  try {\n    const result = await textGenerator(text, {\n      max_new_tokens: 150,\n      temperature: 0.7,\n      top_p: 0.9,\n    });\n    return result[0].generated_text.substring(text.length).trim();\n  } catch (err) {\n    return `Chyba v modelu: ${err.message}`;\n  }\n}\n\n// Spusťte inicializaci při načtení\nwindow.addEventListener('load', initModel);\n```\n\n#### Varianta B: Lokální backend (llama.cpp)\n\n**Přidejte do `app.js`:**\n\n```javascript\nconst BACKEND_URL = 'http://localhost:8080'; // nebo http://127.0.0.1:8080\n\nasync function generateReplyBackend(text) {\n  try {\n    const response = await fetch(`${BACKEND_URL}/v1/completions`, {\n      method: 'POST',\n      headers: { 'Content-Type': 'application/json' },\n      body: JSON.stringify({\n        prompt: text,\n        n_predict: 150,\n        temperature: 0.7,\n        top_p: 0.9,\n        stop: ['\\n\\n', 'Uživatel:', 'User:'],\n      }),\n    });\n\n    if (!response.ok) throw new Error(`Server error: ${response.status}`);\n    \n    const data = await response.json();\n    return data.choices[0].text.trim();\n  } catch (err) {\n    console.error('Backend error:', err);\n    return `Chyba spojení s modelem: ${err.message}`. Zkontrolujte, je-li server běžící.`;\n  }\n}\n\n// V hlavní send() funkci nahraďte generateReply():\nasync function send() {\n  const text = input.value.trim();\n  if (!text) return;\n  \n  addMessage('user', text);\n  input.value = '';\n  input.style.height = 'auto';\n  showTyping();\n  \n  setTimeout(async () => {\n    document.querySelector('#typing')?.remove();\n    const reply = await generateReplyBackend(text); // nebo generateReplyLocal(text)\n    addMessage('ai', reply);\n  }, 300);\n}\n```\n\n#### Varianta C: Vzdálený API backend (s autentizací)\n\n**Pro bezpečné nasazení na serveru:**\n\n```javascript\nasync function generateReplyAPI(text, apiKey) {\n  try {\n    const response = await fetch('https://your-api.com/chat', {\n      method: 'POST',\n      headers: {\n        'Content-Type': 'application/json',\n        'Authorization': `Bearer ${apiKey}`,\n      },\n      body: JSON.stringify({ message: text }),\n    });\n\n    const data = await response.json();\n    return data.reply || 'Serveru se nepodařilo vygenerovat odpověď.';\n  } catch (err) {\n    return `Chyba API: ${err.message}`;\n  }\n}\n```\n\n---\n\n## Doporučené GGUF modely pro češtinu\n\n| Model | Velikost | Zdroj | Kvalita |\n|-------|----------|-------|----------|\n| Llama 2 7B | ~4 GB | Meta / Hugging Face | Dobrá, anglicky orientovaná |\n| Mistral 7B | ~4 GB | Mistral AI | Lepší jazykové chování |\n| Openchat 3.5 | ~4 GB | OpenChat | Velmi konverzační |\n| Llama 3 8B | ~5 GB | Meta | Nejnovější, nejlepší |\n| Czech-LLaMA | ~7 GB | Vlastní | Optimalizovaná pro češtinu (pokud existuje) |\n\n**Stažení z Hugging Face:**\n\n```bash\nhuggingface-cli download TheBloke/Mistral-7B-Instruct-v0.1-GGUF mistral-7b-instruct-v0.1.Q4_K_M.gguf --local-dir ./models\n```\n\n---\n\n## Tipy pro produkci\n\n1. **Paměť:** GGUF modely lze kvantizovat (Q4_K_M, Q5_K_S) pro zmenšení bez ztráty kvality.\n2. **GPU:** Používejte `--gpu-layers` v llama.cpp — čím víc, tím rychlejší inference.\n3. **Konkurrency:** Llama.cpp server zvládne paralelní dotazy, ale paměť GPU je limitná.\n4. **Timeout:** Nastavte v backendu rozumný limit (např. 60 sekund na odpověď).\n5. **Bezpečnost:** Nikdy neposílejte API klíč v JavaScriptu — běžte pouze přes váš backend.\n6. **Monitoring:** Sledujte latenci a paměť — velké modely na slabém hardwaru = špatný uživatelský zážitek.\n\n---\n\n## Offline režim + Přeplutí\n\nChatBot-AI již ukládá historii lokálně. Pokud přidáte WebAssembly model:\n\n- Bez připojení: model běží, historie se synchronizuje později\n- Bez paměti: fallback na demo odpovědi\n- Bez GPU: CPU inference, pomalejší, ale funkční\n\n---\n\n## Příštím krokem\n\nPo zapojení modelu přidáte:\n\n- nastavovací panel pro teplotu, top_p, max_tokens,\n- indikátor loading stavu,\n- storage pro API klíč (bezpečně, jen lokálně),\n- přepínač mezi režimy (demo ↔ backend ↔ WebAssembly),\n- logování a diagnostiku.\n"
